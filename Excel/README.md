# Bike Sales Analysis Dashboard (Microsoft Excel)

## Project Overview
This project focuses on analyzing bike sales data using Microsoft Excel to understand customer purchasing behavior and identify key factors influencing bike purchases.

The analysis explores customer demographics, including gender, income, age groups, commute distance, and regional demographics to identify purchasing patterns and trends.

## Objectives
- Understand customer purchasing behavior and identify key customer segments.
- Analyze bike purchasing patterns based on demographic factors.
- Identify relationships between customer characteristics and purchasing decisions.
- Present key findings through an interactive Excel dashboard.

## Tools & Skills
- **Microsoft Excel**
- Data Cleaning & Transformation
- Pivot Tables
- Pivot Charts
- Data Analysis
- Data Visualization
- Dashboard Development

## Project Workflow

1. **Data Cleaning:** Standardized inconsistent categorical values, formatted customer demographic data, and ensured data consistency for analysis.

2. **Data Transformation:** Created age groups to categorize customers into different demographic segments for easier comparison and analysis.

3. **Exploratory Data Analysis:** Used Pivot Tables to examine bike purchasing patterns based on gender, income, age groups, commute distance, and regional demographics.

4. **Data Visualization:** Created Pivot Charts to visualize customer purchasing patterns and compare different customer segments.

5. **Dashboard Development:** Developed an interactive Excel dashboard to present key findings and provide a clear overview of bike sales performance and customer purchasing behavior.

## Key Analysis Areas

- **Gender Analysis:** Examined bike purchasing patterns across male and female customers.
- **Income Analysis:** Compared customer income levels to understand purchasing behavior.
- **Age Group Analysis:** Identified purchasing patterns across different customer age groups.
- **Commute Distance Analysis:** Explored how commute distance relates to bike purchasing decisions.
- **Regional Analysis:** Compared customer purchasing patterns across different geographical regions.
