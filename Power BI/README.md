# Power BI Data Analysis Project

## Project Overview
This project demonstrates my ability to transform raw data into meaningful business insights using Microsoft Power BI. The project focuses on data preparation, data modeling, analysis, and interactive dashboard development to support data-driven decision-making.

## Objectives
- Transform and prepare raw data for analysis.
- Analyze key metrics and identify business trends.
- Develop an interactive dashboard to visualize important insights.
- Present data in a clear and meaningful way to support business decisions.

## Tools & Skills
- **Microsoft Power BI**
- Power Query (Data Cleaning & Transformation)
- Data Modeling
- DAX (Data Analysis Expressions)
- Data Visualization
- Interactive Dashboard Development

## Project Workflow

1. **Data Cleaning:** Used Power Query to clean, transform, and prepare the dataset for analysis.
2. **Data Modeling:** Organized data relationships to support accurate analysis.
3. **Data Analysis:** Applied DAX measures and calculations to analyze key metrics.
4. **Dashboard Development:** Created interactive visualizations, charts, and KPI indicators to highlight important findings.
