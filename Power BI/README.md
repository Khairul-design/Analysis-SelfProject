# Data Professional Survey Dashboard (Power BI)

## Project Overview
This project focuses on analyzing survey data from data professionals to understand industry trends, salary distributions, job roles, and career preferences.

Using Microsoft Power BI, the survey data was transformed into interactive visualizations to explore the data analytics industry, including salary satisfaction, preferred programming languages, work-life balance, and career entry challenges.

## Objectives
- Analyze salary distributions across different data professional roles.
- Identify the most popular programming languages among data professionals.
- Explore geographical distribution and job roles within the data industry.
- Evaluate salary satisfaction and work-life balance.
- Present survey findings through an interactive dashboard.

## Tools & Skills
- **Microsoft Power BI**
- Power Query (Data Cleaning & Transformation)
- DAX (Data Analysis Expressions)
- Data Modeling
- Data Visualization
- Interactive Dashboard Development

## Project Workflow

1. **Data Preparation:** Imported the survey dataset into Power BI and examined its structure, columns, and data types.

2. **Data Cleaning:** Used Power Query to clean and transform survey responses, ensuring data consistency and preparing the dataset for analysis.

3. **Data Modeling:** Organized the dataset to support accurate calculations and effective data visualization.

4. **Data Analysis:** Applied DAX measures and calculations to analyze average salaries, job distributions, programming language preferences, and satisfaction levels.

5. **Dashboard Development:** Created interactive visualizations using bar charts, column charts, treemaps, and gauges to present key survey findings.

6. **Data Interpretation:** Analyzed the dashboard results to identify trends and patterns in the data professional industry.

## Key Analysis Areas

- **Job Role Analysis:** Examined the distribution of respondents across different data-related job positions.
- **Salary Analysis:** Compared average salaries across different data professional roles.
- **Programming Language Preferences:** Identified the most popular programming languages used by survey respondents.
- **Geographical Analysis:** Explored the geographical distribution of data professionals.
- **Salary Satisfaction:** Evaluated respondents' satisfaction with their current salaries.
- **Work-Life Balance:** Examined work-life balance ratings among data professionals.
- **Career Entry Challenges:** Explored challenges faced by individuals entering the data analytics industry.

## Dashboard Features

- Interactive charts and visualizations.
- KPI indicators for key survey metrics.
- Bar charts and column charts for comparative analysis.
- Treemaps for programming language preferences.
- Gauges for salary satisfaction and work-life balance.
- Interactive filters for exploring survey responses.
