# Global Layoffs Data Analysis (MySQL)

## Project Overview
This project focuses on analyzing global layoffs data using MySQL to identify workforce reduction trends across companies, industries, countries, and different years.

The objective is to explore the dataset, perform SQL-based analysis, and uncover meaningful insights into global layoff patterns.

## Objectives
- Identify companies and industries with the highest number of layoffs.
- Analyze layoff trends across different countries and years.
- Calculate monthly layoffs and cumulative totals.
- Rank the top 5 companies with the highest layoffs each year.

## Tools & Skills
- **MySQL**
- Data Exploration
- Aggregate Functions (SUM, MAX, MIN)
- GROUP BY & ORDER BY
- Common Table Expressions (CTEs)
- Window Functions
- DENSE_RANK()
- Rolling Total Analysis

## Project Workflow

1. **Data Exploration:** Explored the dataset to understand its structure, identify key attributes, and examine layoff records.

2. **Aggregate Analysis:** Used SUM(), MAX(), and MIN() with GROUP BY to analyze layoffs by company, industry, country, and funding stage.

3. **Time-Based Analysis:** Analyzed yearly and monthly layoff trends to identify workforce reduction patterns over time.

4. **Advanced SQL Analysis:** Applied CTEs and Window Functions to calculate cumulative monthly layoffs and rank the top 5 companies with the highest layoffs for each year.

5. **Data Interpretation:** Examined the results to identify significant layoff patterns across companies, industries, and geographical regions.
